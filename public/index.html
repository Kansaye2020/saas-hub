            Guide d'Intégration API & Webhooks
          

          

            Comment connecter n'importe quel SaaS, script, ou outil No-Code (Make, n8n) à ce Hub de paiement.
          

        


        
        

          

            1
            Créer un paiement depuis votre SaaS (Requête HTTP POST)
          

          

            Votre application SaaS envoie une requête POST /api/v1/payments/create avec le header X-Hub-Api-Key.
          

          
curl -X POST http://localhost:4000/api/v1/payments/create \
  -H "Content-Type: application/json" \
  -H "X-Hub-Api-Key: VOTRE_CLE_API_SAAS" \
  -d '{
    "provider": "auto",
    "amount": 2000,
    "currency": "XOF",
    "orderId": "commande_12345",
    "description": "Recharge de crédits",
    "returnUrl": "https://monsaas.com/success",
    "customer": {
      "email": "client@example.com",
      "name": "Jean Dupont"
    }
  }'

        


        
        

          

            2
            Vérifier la signature HMAC-SHA256 du Webhook reçu sur votre SaaS
          

          

            Lorsque le client valide son paiement (Mobile Money ou Carte), le Hub appelle votre webhookUrl avec le header X-Hub-Signature: sha256=....
          

          

            // Exemple de vérification de signature en Node.js (Express / Next.js) :

            const crypto = require("crypto");


            function verifyHubWebhook(rawBody, receivedSignature, webhookSecret) {

              const hmac = crypto.createHmac("sha256", webhookSecret).update(rawBody).digest("hex");

              const expected = `sha256=${hmac}`;

              return crypto.timingSafeEqual(Buffer.from(receivedSignature), Buffer.from(expected));

            }
          

        


        
        

          

            
            SDK TypeScript / Node.js inclus
          

          

            Un client SDK prêt à l'emploi est inclus directement dans le dossier sdk/client.ts de ce projet. Vous pouvez simplement le copier-coller dans votre projet SaaS pour créer des paiements et vérifier les signatures en 2 lignes de code !
